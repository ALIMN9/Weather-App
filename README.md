# Dynamic Weather App

A weather application that changes its background and gradients based on the current weather and time of day (day/night). 

## Features
- Search for weather by city name (Geocoding API).
- Displays temperature, humidity, description, and local time.
- Dynamic CSS radial-gradients that change based on weather conditions and day/night cycles.

## Setup Instructions
1. Clone this repository.
2. Create a free API key at [OpenWeatherMap](https://openweathermap.org/).
3. Rename `config.example.js` to `config.js`.
4. Add your API key inside `config.js`:
   `const apiKey = "YOUR_API_KEY_HERE";`
5. Open `index.html` in your browser.
